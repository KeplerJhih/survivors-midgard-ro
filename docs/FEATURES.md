# 功能開關與優化紀錄

## 開關（popup）

| 開關 | 預設 | 生效 | 作用 | 實作 |
|---|---|---|---|---|
| 模擬 iPhone | 開 | 重新整理遊戲頁 | 偽裝 UA / platform / maxTouchPoints / `pointer: coarse` | `core/spoof/mobile.ts`、`entrypoints/mobile.content.ts` |
| 滑鼠拖曳轉觸控 | 開 | 即時 | 手機模式下滑鼠拖曳 → 單指觸控（操作虛擬搖桿、點 UI） | `core/touch/mouse-to-touch.ts` |
| 背景持續執行 | 開 | 重新整理遊戲頁 | 接管 rAF；隱藏或 rAF 逾時 100ms 由 Worker 時脈推進 | `core/background/raf.ts`、`ticker.ts` |
| 啟用掛機 | 關 | 即時 | 走位＋選卡＋（選用）Enter | `core/bot/bot.ts` |
| 走位 | 花瓣 | 即時 | 花瓣（每圈轉黃金角，掃過半徑 2R 圓盤）/ 8 字形 / 繞圈 / 原地 | `core/movement/strategies.ts` |
| 走位週期 | 4000ms | 即時 | 越大繞得越大 | |
| 選卡間隔 | 1500ms | 即時 | 週期送 `1` | |
| MVP 後自動走回地圖 | 開 | 即時 | 畫面辨識青色傳送門、避開紅色 | `core/vision/portal.ts` |
| 躲紅色預警框 | 開 | 即時 | 角色腳下與 8 方向探測深紅色技能範圍，腳下紅就逃、前方紅就改走最近的安全方向 | `core/vision/danger.ts` |
| 自動前往寶箱 / NPC | 開 | 即時 | 辨識畫面外指示器（深色圓盤＋圖示）：大圓盤＝傳送門/任務（含紫色 MVP 入口）優先前往、小圓盤暖色＝寶箱前往、小圓盤紫色＝催眠師避開；連續 2 次才動作，追 30 秒未到放棄冷卻 20 秒 | `core/vision/indicators.ts` |
| 自動再玩一次 | 開 | 即時 | 畫面辨識：結算頁→再玩一次、升級→點稀有度最高的卡、選地圖→選擇（沿用預設地圖）、準備→出發冒險、腐化寶箱→Valhalla、置中視窗→主要按鈕（新卡片「繼續」等）、確認框→仍要離開/繼續、初始技能→上次選擇 | `core/vision/screens.ts`、`core/input/pointer.ts` |
| Debug 面板與 log | 關 | 即時 | 左下狀態面板；console `[MSBot]` | `core/debug/overlay.ts` |

建議的遊戲內設定（暫停選單 Esc 或升級視窗下方的勾選框，**永久保存**）：
- 「累積寶箱」：寶箱不再暫停對局
- 「隨機選擇」（`endless_auto_pick`）：升級自動選卡，**依稀有度挑最高**（進化 > 傳說 > 史詩 > 稀有 > 普通），同稀有度依 ⚙ 優先順序，沒設定就在最高稀有度中隨機；不跳窗、不暫停（`core/auto_pick.gd` `_best`）

## 模組與規劃

| 模組 | 已完成 | 規劃中 |
|---|---|---|
| 輸入層 `core/input`、`touch` | 合成鍵盤、觸控點擊、滑鼠轉觸控 | — |
| 環境層 `spoof`、`background` | iPhone 偽裝、背景執行＋看門狗 | 排查重新載入時注入既有分頁偶發失敗 |
| 視覺辨識 `core/vision` | 視窗（結算/腐化/升級稀有度/選地圖/置中/確認框/初始技能）、傳送門、畫面外指示器、紅色預警框 | 畫面內物件（木箱/鐵箱、地上寶箱彈跳箭頭）；HUD 讀取（HP 比例、遊戲時間是否前進）；非紅色預警（紫色影子） |
| 決策層 `core/bot` | 優先順序：視窗 > 出口 > 目標 > 巡邏，最後套紅框躲避 | 場景狀態機（城鎮/選圖/野外/MVP/結算）；低血量行為；卡住偵測自動脫困 |
| 走位 `core/movement` | 花瓣、8 字形、繞圈、原地 | MVP 風箏（大圈、與 Boss 保持距離） |
| 統計與紀錄（新） | — | 每局存活/等級/死因/MVP；每小時 Zeny/經驗；匯出比較 |
| 介面 `popup`、`overlay` | 開關、重新載入、debug 面板 | 統計顯示；預設組合（安全掛機 / 積極刷寶） |
| 測試 `tests/` | 85 個單元測試（合成畫面） | 錄製實機畫面當回歸素材 |

建議順序：MVP 風箏 + 低血量行為（解決死亡）→ 卡住偵測（長時間無人看管）→ 畫面內物件 → 統計穿插進行。

## 待辦 / 想法

- 畫面內的目標（指示器消失、改為頭上彈跳箭頭）目前靠花瓣走位掃過，尚未主動導航
- 任務 NPC 接任務視窗（_ro_button「我來幫忙！」，非藍框主要按鈕）待實機校準點擊
- 紫色「深淵墜擊」影子等非紅色預警尚未躲避
- 偵測升級選卡視窗後再按，取代週期送 `1`（目前在非選卡畫面遊戲會忽略，風險低）
- 偵測死亡 / 結算畫面並記錄（不自動開新局）
- 統計面板：每小時 Zeny / 經驗 / MVP 次數（需 OCR 或畫面辨識 HUD）
- 低血量時遠離怪物（需辨識 HP 條）
