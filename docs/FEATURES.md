# 功能開關與優化紀錄

## 開關（popup）

| 開關 | 預設 | 生效 | 作用 | 實作 |
|---|---|---|---|---|
| 模擬 iPhone | 開 | 重新整理遊戲頁 | 偽裝 UA / platform / maxTouchPoints / `pointer: coarse` | `core/spoof/mobile.ts`、`entrypoints/mobile.content.ts` |
| 滑鼠拖曳轉觸控 | 開 | 即時 | 手機模式下滑鼠拖曳 → 單指觸控（操作虛擬搖桿、點 UI） | `core/touch/mouse-to-touch.ts` |
| 背景持續執行 | 開 | 重新整理遊戲頁 | 接管 rAF；隱藏或 rAF 逾時 100ms 由 Worker 時脈推進 | `core/background/raf.ts`、`ticker.ts` |
| 啟用掛機 | 關 | 即時 | 走位＋選卡＋（選用）Enter | `core/bot/bot.ts` |
| 走位 | 花瓣 | 即時 | 花瓣（每圈轉黃金角，掃過半徑 2R 圓盤）/ 8 字形 / 繞圈 / 原地 | `core/movement/strategies.ts` |
| 走位週期 | 4000ms | 即時 | 越大繞得越大 | |
| 選卡間隔 | 1500ms | 即時 | 週期送 `1` | |
| MVP 後自動走回地圖 | 開 | 即時 | 畫面辨識青色傳送門、避開紅色 | `core/vision/portal.ts` |
| 自動再玩一次 | 開 | 即時 | 畫面辨識：結算頁→再玩一次、腐化寶箱→Valhalla、置中視窗→主要按鈕（新卡片「繼續」等）、確認框→仍要離開/繼續、初始技能→上次選擇 | `core/vision/screens.ts`、`core/input/pointer.ts` |
| 自動按 Enter | 關 | 即時 | 寶箱/結算；⚠️ 城鎮會開聊天；⚠️ 腐化寶箱會選到 Hel | |
| Debug 面板與 log | 關 | 即時 | 左下狀態面板；console `[MSBot]` | `core/debug/overlay.ts` |

建議的遊戲內設定（暫停選單 Esc 或升級視窗下方的勾選框，**永久保存**）：
- 「累積寶箱」：寶箱不再暫停對局
- 「隨機選擇」（`endless_auto_pick`）：升級自動選卡，**依稀有度挑最高**（進化 > 傳說 > 史詩 > 稀有 > 普通），同稀有度依 ⚙ 優先順序，沒設定就在最高稀有度中隨機；不跳窗、不暫停（`core/auto_pick.gd` `_best`）

## 優化紀錄

| 日期 | 問題（觀察） | 處置 | 驗證 |
|---|---|---|---|
| 11-24 | 寶箱視窗暫停對局，Enter 關閉時掛機空轉 | 遊戲內勾「累積寶箱」 | 實機：之後寶箱改顯示「已保留 N 個寶箱」 |
| 11-24 | 視窗被遮住時 rAF 停止但 visibility 仍 visible，遊戲停住 | keepalive 加看門狗（逾時 100ms 接手） | 單元測試；實機待驗 |
| 11-24 | 重新整理後掛機停在停用（bridge/bot 載入順序競態） | bot 收到設定前每 500ms 重送請求 | 實機：重新要設定後恢復 |
| 11-24 | MVP 打完停在 MVP 房，繞圈可能誤踩紅色傳送門 | 畫面辨識導航到返回地圖傳送門（連續 3 次確認、避開紅色） | 顏色依實機取樣校準；單元測試；實機待驗 |
| 11-24 | 繞圈範圍小，經過的掉落物少 | 新增 8 字形走位（上下兩圓，零漂移） | 模擬：Lissajous 版每週期漂移半個圖形，已捨棄 |
| 11-24 | 腐化寶箱選路線視窗卡住對局 | 手動選 Valhalla；查出 Enter 會選 Hel → popup/文件加警告 | 實機：選後對局恢復 |
| 11-24 | MVP 入口傳送門開啟後一直等角色踩進去，8 字形碰不到 → 對局卡住（遊戲時間停在 13:00） | 手動走入；新增花瓣走位並設為預設 | 模擬：半徑 0.6R~1.8R 覆蓋率 >95% |
| 11-24 | 使用者開了自動 Enter，換地圖時腐化寶箱會被選成 Hel | 該分頁暫時關閉 Enter（未改儲存設定） | — |

| 11-25 | 新局腐化寶箱又跳窗（換局/換圖重設路線） | 新增腐化寶箱辨識，點 Valhalla 卡片底部按鈕 | 實機取樣標題色；實機點擊 Valhalla 成功 |
| 11-25 | 「新卡片！」視窗暫停對局（背景不壓暗，確認框規則抓不到） | 新增置中視窗＋主要按鈕規則 | 實機：算出的點擊落在「繼續」，視窗關閉 |
| 11-25 | 死於第二隻 Baphomet（固定走位不躲技能），停在結算頁 | 新增自動再玩一次（結算/確認框/初始技能畫面辨識＋合成觸控點擊） | 實機：觸控點擊流程走完一輪；實機 30 次取樣 0 誤判；單元測試 |
| 11-24 | 重新載入外掛要刷新遊戲、中斷對局 | 外掛 onInstalled 時把新版 bot/bridge 注入既有分頁，舊實例 dispose | 實機待驗 |

## 待辦 / 想法

- **MVP 戰大範圍繞圈＋辨識地面紅色預警框自動躲開**（需 MVP 戰時取樣校準）
- **寶箱導航**：辨識畫面外指示器（半徑 0.4×H 圓周上的彩色外框圓）取得方位，走過去（3~20 單位）；避開紫色催眠師
- 金波利出現時追擊
- 偵測升級選卡視窗後再按，取代週期送 `1`（目前在非選卡畫面遊戲會忽略，風險低）
- 偵測死亡 / 結算畫面並記錄（不自動開新局）
- 統計面板：每小時 Zeny / 經驗 / MVP 次數（需 OCR 或畫面辨識 HUD）
- 低血量時遠離怪物（需辨識 HP 條）
