- 「累積寶箱」：寶箱不再暫停對局
- 「隨機選擇」（`endless_auto_pick`）：升級自動選卡，**依稀有度挑最高**（進化 > 傳說 > 史詩 > 稀有 > 普通），同稀有度依 ⚙ 優先順序，沒設定就在最高稀有度中隨機；不跳窗、不暫停（`core/auto_pick.gd` `_best`）

## 辨識原則

- **結構特徵優先**：版面解析（`core/vision/layout.ts`）以亮度邊緣切出面板/按鈕/卡片，依形狀、大小、排列判斷畫面（`core/vision/ui-rules.ts`），不靠特定 UI 顏色。
- 只有遊戲本身以顏色表達的資訊才比較顏色（例如升級卡的稀有度外框）。
- 舊的顏色規則（`core/vision/screens.ts`）只保留特徵獨特的「結算頁」「腐化寶箱」作為備援，其餘已停用（城鎮誤判）。
- 驗證方式：在頁面錄製實機畫面（640px），將新規則套在錄製畫面上比對，再貼回頁面截圖人工核對。
